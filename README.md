# summarize-exam-points

一个可开源的 Agent Skill：输入教材、课堂笔记等**纯文本**，自动提炼闭卷考试中简答题 / 论述题的**踩分提纲、背诵口诀与标准答题框架**。

## 1. 项目解决什么问题

备考闭卷考试时，学生常遇到这些痛点：

- 教材和笔记篇幅大、重点不突出，复习时抓不住"会考什么、怎么答"。
- 背了很多却不会组织答案，考试时抄满原文也拿不到分。
- 自己整理考点费时，且容易把零散、重复的内容一股脑堆上去。

本 Skill 把大段教材或笔记**浓缩成可直接背诵、可直接照着答题的高频考点**，并守住三条底线：

- **忠实原文**：每一条踩分点都能在原文找到依据，绝不编造、绝不补充原文没有的信息。
- **去重合并**：同一概念多处出现时合并为一条，删除冗余表述。
- **宁缺毋滥**：信息不足时明确标注"原文信息不足"，不强行凑数量。

## 2. 主要功能

- **按题型输出框架**：自动判定"简答 / 论述"题型（简答重要点罗列，论述重多角度分析 + 评价），给出深度匹配的答题框架。
- **踩分提纲**：对每个考点按"概念/定义 → 核心要点 → 总结/意义"组织，要点附带**原文踩分词**。
- **背诵口诀**：为每个考点配 1–2 行易记短句（首字连词、数字概括、谐音、对比等），只辅助记忆、不替代要点、不引入事实性断言。
- **原文依据标注**：每个考点回指原文段落或可引用原句，方便回溯核对。
- **考点总览表**：材料含 3 个及以上考点时，先给总览表便于总览。
- **多学科适配**：历史、理科、文学、法律 / 管理等均有针对性提示（如理科重"定义—条件—公式—应用"，历史重"背景—内容—影响"）。

## 3. 安装方法

本 Skill 是一个标准 Skill 包，目录为 `skills/summarize-exam-points/`，内含 `SKILL.md` 与 `agents/openai.yaml`。安装即"放置目录"：

**方式 A：放入用户级 Skill 目录（对所有项目生效）**

```bash
# 将整个 skill 目录复制到用户 Skill 目录
cp -r skills/summarize-exam-points ~/.workbuddy/skills/
```

**方式 B：放入当前项目（仅本项目生效）**

直接将 `skills/summarize-exam-points/` 保留在项目内 `skills/` 目录下即可，无需额外配置。

> 安装后，在支持 Skill 的 agent 环境中，粘贴教材/笔记文本或用一句话触发即可自动调用。本 Skill 不依赖任何外部脚本或额外依赖。

## 4. 使用方法

1. **触发**：在对话中直接**粘贴**教材段落或课堂笔记文本，或用一句话触发，例如：
   > "帮我提炼这段笔记的考点，按简答和论述分别给我踩分提纲和背诵口诀。"
2. **获取结果**：Skill 会自动判定题型，输出踩分提纲、背诵口诀与标准答题框架；多个考点时还会先给总览表。
3. **按需裁剪**：若你只想要某一类内容（如只要口诀或只要提纲），在请求中说明，Skill 会只输出对应部分，不套用完整模板。

## 5. 输入 / 输出示例

### 输入示例（粘贴的纯文本）

> 生产力是社会生产中最活跃的因素。它包括劳动者、劳动资料和劳动对象三个要素。科学技术是第一生产力，能极大提升生产效率。

### 输出示例

```markdown
## 考点 1：生产力（题型：简答）

**背诵口诀：** 三要素—劳者料象；科技第一生产力。

**标准答题框架：**
1. **概念/定义：** 生产力是社会生产中最活跃的因素。
2. **核心要点：**
   - ① 三要素：劳动者、劳动资料、劳动对象（踩分词：劳动者、劳动资料、劳动对象）
   - ② 科技定位：科学技术是第一生产力（踩分词：第一生产力）
3. **总结/意义：** 科技能极大提升生产效率。

**原文依据：** 原文片段全文。
```

## 不支持的功能

- 网页链接抓取 / 网页解析
- PDF 文件解析
- Anki 卡片生成
- 任何图形界面（GUI）操作

遇到上述输入时，Skill 会提示你直接粘贴纯文本。
