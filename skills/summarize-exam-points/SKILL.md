# 考点提炼（Summarize Exam Points）

## Overview

将教材、课堂笔记等纯文本，转化为闭卷考试中简答题与论述题的「踩分提纲 + 背诵口诀 + 标准答题框架」。目标是帮用户在有限复习时间内抓住真正会考、能得分的核心知识，而不是堆砌原文或凑数量。

## 适用范围与输入要求

- 仅接受用户直接粘贴的纯文本：教材段落、课堂笔记、讲义、复习资料等。
- 以原文语义为准，处理中文或中英混合材料。
- 不处理以下内容，遇到时应先说明限制并请用户提供纯文本：
  - 网页链接 / 网页抓取（URL、在线文章）
  - PDF 文件解析
  - Anki 卡片生成
  - 任何图形界面（GUI）操作

## 核心原则（最高优先级）

1. **忠实原文**：每一条踩分点都必须能在原文中找到依据。不得编造、臆测或补充原文没有的定义、数据、年份、人名、结论；不得将「可能」「一般」升级为确定结论。
2. **去重合并**：同一概念在多处出现时，合并为一条考点，保留最完整、最准确的表述，避免重复罗列。
3. **宁缺毋滥**：当某段材料信息过于单薄、不足以支撑一个完整考点时，要么明确标注「原文信息不足，暂不列为独立考点」，要么不列出；绝不为了凑数量而强行拆分或注水。
4. **抓大放小**：优先提炼高频可考结构——定义/概念、特征、原因/背景、意义/影响、区别/联系、步骤/流程、原则/要求；忽略举例性、过渡性、口语化内容，除非它本身即为考点。

## 工作流程

1. 通读全文，标出所有潜在可考知识点，并判定其更可能以「简答」还是「论述」形式出现：
   - **简答**：知识记忆型，直接列出要点即可得分（定义、特征、步骤等）。
   - **论述**：理解分析型，需「是什么—为什么—怎么样/意义」多角度展开，常要求评价或结合材料。
2. 合并重复：将表达同一考点的分散内容归并，删去冗余表述；同时避免把一个完整考点无意义地拆碎，也避免把多个独立考点硬并。
3. 对每个考点，按「定义 → 要点 →（总结/意义）」的答题逻辑组织踩分点，每条要点附上原文关键词。若原文无明确定义句，用「指……」概括原文描述，不得添加原文没有的限定或改写本义。
4. 编写背诵口诀：用首字连词、数字概括、谐音或对比等方式，把要点压缩成易记短句（1–2 行）。口诀可运用修辞（比喻、对仗）辅助记忆，但**不得借口诀引入原文没有的事实性断言**；口诀只是助记，不替代要点本身。
5. 给出标准答题框架（见下），让用户知道考试时如何展开。
6. 标注原文依据（段落位置或可引用原句），方便回溯核对。
7. 组织呈现：提炼出 **3 个及以上考点**时，先给「考点总览表」，再逐项展开；不足 3 个可直接展开。若用户仅要求某一部分（如只要口诀或只要提纲），则只输出对应部分，不必套用完整模板。

## 题型判定速查

- 出现「简述 / 列举 / 是什么 / 有哪些」→ 通常判为**简答**，框架以要点罗列为主。
- 出现「分析 / 评述 / 说明意义 / 如何理解 / 比较」→ 通常判为**论述**，框架需含背景、多角度分析、总结评价。

## 输出格式

严格使用以下 Markdown 模板，每个考点一个二级标题：

```markdown
## 考点 N：<考点名称>（题型：简答 / 论述）

**背诵口诀：** <1–2 行易记短句>

**标准答题框架：**
1. **概念/定义：** <原文中的定义句，可缩写但不得改义>
2. **核心要点：**
   - ① <要点一>（踩分词：<原文关键词>）
   - ② <要点二>（踩分词：<原文关键词>）
   - ③ ……
3. **总结/意义/影响：** <原文结论或升华句>

**原文依据：** <第几段 / 可引用的原句>
```

可选「考点总览表」（置于最前，便于总览）：

| 编号 | 考点 | 题型 | 背诵口诀 |
|------|------|------|----------|
| 1 | … | 简答 | … |
| 2 | … | 论述 | … |

## 按材料类型调整

- **文科 / 历史类**：重点抓「背景—内容—影响」「原因—经过—意义」；论述题常用「政治 / 经济 / 文化 / 国际」多角度框架。
- **理科 / 工科类**：重点抓「定义—条件/前提—公式/规律—应用/特例」；踩分词常为术语与限定条件。
- **文学 / 艺术类**：重点抓「主题—手法—人物形象—艺术特色」；论述题强调文本依据 + 分析。
- **法律 / 管理类**：重点抓「概念—构成要件—原则—法律责任/应用」。
- **短笔记 / 碎片化材料**：信息稀疏时，宁可产出较少考点并标注依据，也不要拼凑。

## 输入 / 输出示例

**输入（教材片段）：**
> 科举制创立于隋朝，完善于唐朝。它通过考试选拔人才，打破了世家大族对官场的垄断。科举制加强了中央集权，扩大了统治基础，但也束缚了知识分子的思想，阻碍了科技文化的发展。

**输出：**
## 考点 1：科举制（题型：简答）

**背诵口诀：** 隋创立、唐完善，考试选才破垄断；集权扩基缚思想，利弊双存记心间。

**标准答题框架：**
1. **概念/定义：** 科举制是通过考试选拔官吏的制度。
2. **核心要点：**
   - ① 发展历程：隋朝创立、唐朝完善（踩分词：隋朝、唐朝）
   - ② 选拔方式：以考试选才，打破世家大族垄断（踩分词：考试选拔、打破垄断）
   - ③ 积极影响：加强中央集权、扩大统治基础（踩分词：中央集权、统治基础）
   - ④ 消极影响：束缚思想、阻碍科技文化（踩分词：束缚思想、阻碍发展）
3. **总结/意义：** 科举制是一把双刃剑，利弊并存。

**原文依据：** 教材片段全文。

## 禁止事项

- 不编造原文没有的信息、数据、年份、人名。
- 不把推测写成定论。
- 不重复罗列同一考点。
- 不输出与考试答题无关的内容（闲聊、原文全文复述）。
- 不支持：网页抓取、PDF 解析、Anki、GUI。
